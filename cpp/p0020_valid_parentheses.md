# 0020 · Valid Parentheses · C++17

[原题](https://leetcode.com/problems/valid-parentheses/) · [实现](p0020_valid_parentheses.cpp) · [测试](../tests/cpp/test_p0020_valid_parentheses.cpp)

输入只含三种括号的开闭符号，判断类型和嵌套顺序是否都匹配。用`Solution::isValid(string)`接口；算法不依赖全局或跨调用状态。

把还未匹配的开括号转换成“未来需要的闭括号”，存入栈。遇到`(`、`[`、`{`分别压入`)`、`]`、`}`。遇到闭括号时，它必须等于栈顶期望符号，否则立即失败；匹配则弹出。遍历结束还需检查栈为空，不能只确认没有出现错配。

不变量：已扫描前缀如果尚可能构成有效序列，栈从底到顶对应所有未闭合括号的期望闭合字符；最内层必须先结束。因此栈顶决定唯一合法的下一个闭括号。`([)]`虽然三种括号计数配平，但扫描到`)`时栈顶是`]`，应拒绝；只计数无法表达嵌套。

例如`{[()]}`依次把期望栈变为`}`、`}]`、`}])`，接着按`)`、`]`、`}`逐个弹出，最终为空。以`)`开头会在空栈处失败；`(()`结束时仍有期望符号，也失败。

每个字符至多入栈或出栈一次，时间O(n)，额外空间O(n)，最深嵌套时需要线性栈。本实现把空字符串视为有效空序列，遇非括号字符返回false；这两项是明确的接口扩展，不改变原题括号输入的处理。

测试涵盖匹配/错型/交叉嵌套、单边多余括号、多个相邻组、同一对象多次调用、空串和非括号扩展，并用长度10000的深嵌套避免递归栈假设。

A补写不同于栈算法的独立oracle：重复删除相邻的()、[]、{}，直到某轮长度不再减少，最后仅空串有效。删除合法相邻括号对保留嵌套有效性；任何非空有效括号串都存在最内层的相邻合法对，因此有效串能不断缩短至空串。不可再删却非空的串无合法解析。空串扩展对应零次删除，仍有效。
