# 0053 · Maximum Subarray · C++17

[原题](https://leetcode.com/problems/maximum-subarray/) · [实现](p0053_maximum_subarray.cpp) · [测试](../tests/cpp/test_p0053_maximum_subarray.cpp)

在非空整数数组中选一个非空连续子数组，返回最大和。`Solution::maxSubArray(vector<int>&)`不修改输入。采用原题`1 <= n <= 100000`、元素绝对值至多10000的约束；任何连续段的和的绝对值至多10^9，32位int足够。空数组是本地扩展，显式抛invalid_argument，而非让空段参与最优值竞争。

ending表示必须在上一位置结束的最佳非空和。读到nums[i]后，新段只能单独取当前元素，或者延长上一位置的段，因此转移为`max(nums[i], ending + nums[i])`。best保存所有已处理结束位置中的最大值。两个状态从首元素初始化，使全负数组仍选中一个实际元素。

归纳地，长度1前缀的ending与best均正确。任何以i结束且长度大于1的候选，删去末尾后都以i−1结束；其中最大值由旧ending给出。把单元素候选与延长候选取最大便覆盖全部情况，再更新best覆盖全部结束位置。最终best就是答案，不一定等于最终ending。

`[4,-6,3,2,-1]`的ending依次为4、−2、3、5、4，best依次为4、4、4、5、5。最后返回5；若只返回ending会漏掉更早结束的最优段。`[-5,-2,-7]`返回−2，初始化为0会错误允许空子数组。

一次扫描O(n)时间、O(1)额外空间。测试独立枚举每个起点/终点的和，核对长度1至6、元素−2至2的19530个数组；另含6个固定用例、长度100000的正负极限数组和空输入异常，并检查输入不变。

A补写反转性质：长度n数组中的每个非空连续区间[i,j]，在反转数组中一一对应[n−1−j,n−1−i]；元素只是倒序，区间和不变。该映射可逆，所以所有可行区间的和组成相同集合，最大值不变。证明不要求元素非负，也不加入空段，因此全负数组仍返回某个实际元素。
