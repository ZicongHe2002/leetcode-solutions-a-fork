# 84. Largest Rectangle in Histogram · C++17

[原题](https://leetcode.com/problems/largest-rectangle-in-histogram/)中的每根柱子宽度为 1。输入长度为 1..100000，高度为 0..10000；求完全包含在这些柱子中的最大矩形面积。实现提供 `Solution::largestRectangleArea(vector<int>&)`，并保持输入不变。

保存一个按高度严格递增的栈，元素是 `(高度, 最早可用左端点)`。扫描到位置 right 时，当前高度小于栈顶，就说明该候选矩形不能跨过 right：它能覆盖 `[start, right)`，面积为 `previousHeight * (right-start)`。弹出它后，当前较矮高度可以使用同一个 start，于是把左端点向左传递，继续关闭更高候选。

所有较高候选关闭后，若栈顶等高，保留已有元素。它已经拥有更早或相同的左端点，新建同高候选没有收益。若栈为空或栈顶更低，压入当前高度和刚得到的最早左端点。扫描末尾使用一个虚拟高度 0，关闭所有尚未结算的正高度；无需向输入追加哨兵。零高度候选不产生正面积，允许留在栈中。

不变量：在读入下一个位置前，每个栈元素 `(h,start)` 对应一个仍可延伸的候选，`[start,right)` 中每根柱子均不低于 h，且 start 已到达该候选的最左可用位置。更低的前柱会阻止继续向左。压入时，当前柱自己可用；每次弹出的较高区间也全部可用于较低的当前高度，因此传递 start 合法。保留等高旧候选不会丢失更宽答案。遇到更低柱时，候选已到其最右可用位置，结算面积完整。

任何最优矩形都可把高度提升到它覆盖区间中某根最低柱的高度，再向两边延伸到严格更矮的柱子或数组边界；面积不会减小。相应高度的最早候选必被保留，并在右边界或虚拟零柱处结算。所以所有计算均为合法面积，且至少覆盖一个最优面积。

例如 `[4,2,2,1]`：第二根柱关闭面积 4 的高度 4 候选，并把高度 2 的起点设为 0；第三根等高柱保留这个起点；遇到高度 1 时结算 `2*3=6`。若等高时丢掉原起点，会漏掉这块矩形。`[1,2,3,4]` 的主要候选要到虚拟零柱处才结算，不能省略末尾清栈。

每根柱最多压栈一次，每个元素最多弹出一次，所以总时间为 O(n)，栈额外空间为 O(n)。最大面积不超过 `100000*10000=1000000000`，宽度及乘积均在题目使用的 32 位有符号 int 范围内；虚拟末尾的 right 最大为 100000，未越界读取输入。

独立测试 oracle 枚举每个连续区间，逐步维护区间最小高度，以 `最小高度*宽度` 取最大值。它是 O(n²) 的直接定义实现，不使用栈或最近更矮边界。穷举长度 1..8、高度集合 `{0,1,3,4}` 的 87380 个输入，并逐个核对原输入未被修改。14 个手算案例覆盖单柱、等高、零柱分段、连续弹出、末尾清栈和谷底。另有五个长度 100000 的构造：全高 10000（面积 10^9）、全零、全一、中间零柱分割、零与最大高度交替；长度 10000 的递增/递减高度序列均期望 25005000，因为 `h*(10001-h)` 在中间取得最大值。

等高和左端点传递可用 `[2,5,2,4,1]` 展开。栈从底到顶写成 `(高度,起点)`；面积只在候选关闭时结算。位置 2 弹出高度 5 后，当前高度 2 仍保留旧起点 0，不能把它换成刚传来的 1。

| right及当前高度 | 处理动作 | 处理后的栈 | best |
| --- | --- | --- | --- |
| 0，高度2 | 压入(2,0) | [(2,0)] | 0 |
| 1，高度5 | 压入(5,1) | [(2,0),(5,1)] | 0 |
| 2，高度2 | 弹出(5,1)，面积5；等高旧候选保留(2,0) | [(2,0)] | 5 |
| 3，高度4 | 压入(4,3) | [(2,0),(4,3)] | 5 |
| 4，高度1，第一弹 | 弹出(4,3)，面积4，左端点传为3 | [(2,0)] | 5 |
| 4，高度1，第二弹 | 弹出(2,0)，面积8，左端点传为0 | [] | 8 |
| 4，高度1，压入 | 保存传来的最早起点 | [(1,0)] | 8 |
| 5，虚拟高度0 | 弹出(1,0)，面积5；不向输入或栈追加虚拟柱 | [] | 8 |

反转不变性：原数组区间 `[left,right]` 与反转后区间 `[n-1-right,n-1-left]` 一一对应，宽度及最小高度均相同，所以每个可行矩形都有面积相等的对应矩形，两边的最大面积相同。正比例缩放性质：把所有高度乘同一个正整数 c，若变换后高度仍在 0..10000，所有区间的最小高度和面积都乘 c，最大面积也乘 c；零柱仍为零，不会连接原本分开的正面积区间。

新增性质测试对全部 87380 个小数组检查反转结果，并分别按 2、7、2500 缩放后检查面积，共 262140 次缩放核对。原高度至多4，缩放后至多10000，长度仍为1..8；每次也检查输入保持。原有大型边界保留原值，避免非法缩放或越过面积上界。
