# 217. Contains Duplicate · C++17

[原题](https://leetcode.com/problems/contains-duplicate/)询问整数数组中是否有某个值至少出现两次。`bool Solution::containsDuplicate(std::vector<int>& nums)`保留输入顺序和内容。原题非空且至多100000项；空数组自然返回false是扩展，int极值也可安全比较和哈希，不对元素作算术。

seen保存已经扫描前缀中出现过的全部不同值。读取新值时，unordered_set::insert返回的second为false恰好表示这个值已经存在，因此当前下标与某个更早下标构成重复；返回true正确。插入成功时把新值纳入前缀集合，保持不变量。遍历结束仍未遇重复则任意两个位置的值都不同，返回false。只检查相邻元素会漏掉[1,2,3,1]，原数组并未承诺排序。

设n为长度、u为不同值个数，哈希操作平均常数时间时总时间O(n)，集合空间O(u)。不能把unordered_set的平均保证写成碰撞最坏情况下仍线性；极端碰撞可能使总时间达到O(n²)。早停不修改输入，也没有为了查重排序原数组。

测试用所有不同下标对的直接相等比较作为独立oracle，枚举−1、0、1上长度0..7的3280个数组。另有3个明确案例核对非相邻重复和int极值，以及两个100000长度边界（全部不同、仅尾项与首项重复）。大边界用直接构造的明确期望，避免对其运行二次oracle；每次检查输入未变。

A补写输入[2,−1,2,3]的早停账本。集合用排序后的数学集合展示，未假定unordered_set的迭代次序：

| 当前下标 / 值 | 插入前seen | insert.second | 后续行为 |
| --- | --- | --- | --- |
| 0 / 2 | {} | true | seen成为{2}，继续 |
| 1 / −1 | {2} | true | seen成为{−1,2}，继续 |
| 2 / 2 | {−1,2} | false | 已有较早的2，立即返回true |

下标3的3不必访问，但原vector仍完整保持。insert的second只表示“本次是否新插入”，不能把false当作不存在；若只比较相邻项，也看不到相隔一个元素的两个2。

任意下标排列都保留是否存在一对不同位置相等，因为排列是位置的双射，重复对可正反向对应。A以反序作为一个明确排列，对全部3280个小枚举、3个固定案例和2个大边界共3285次exact调用增加性质核对；反序保持值域和长度，INT_MIN/MAX没有取负或算术。反序后另拍快照核对求解器不修改输入。这个测试只实例化反序，不声称穷举了所有排列；一般排列不变性由上述证明给出，原成对比较oracle保留。
