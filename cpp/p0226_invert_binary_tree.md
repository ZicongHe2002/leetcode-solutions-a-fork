# 226. Invert Binary Tree · C++17

[原题](https://leetcode.com/problems/invert-binary-tree/)将每个节点的左右子树互换。`TreeNode* Solution::invertTree(TreeNode* root)`使用judge提供的TreeNode，原地调整child指针并返回同一个根；空根返回nullptr。树必须有效、无环且不共享子节点；算法不创建、删除节点或改变节点值，返回指针仍由调用者拥有。

队列从根开始，每次取出一个节点，交换其left/right，然后把非空孩子加入队列。交换前后两个孩子的集合不变，只交换其左右位置，因此所有原节点仍可到达。有效树中每个非根节点唯一属于一个父节点，故每个节点被排队和处理恰好一次；全部节点各交换一次即满足镜像定义。只交换根会漏掉深层子树。

队列保存指针值，不承担节点所有权；交换时两个指针先由std::swap保存并互换，不会像连续赋值`left=right; right=left`那样丢掉原左孩子。第二次对整树执行相同操作，每个节点再次交换两边，精确恢复原结构。

时间O(n)。队列最多包含相邻两层的部分节点，峰值与最大层宽w同阶，为O(w)额外空间，最坏O(n)；不能只因原地改边就声称算法总辅助空间O(1)。

测试枚举0..6节点全部197种树形及100节点的左右斜链。对所有原节点拍下left/right/value，调用后核对每个原节点的左右边分别等于此前右/左边，值不变、返回根身份不变；第二次调用后核对全部原边恢复。该oracle直接比较每个原节点的合同，不只比较可能重复的值。节点由测试unique_ptr独立拥有，两次验证完成后才析构，不沿修改过的child指针释放。

A补写不对称树：A(2).left=B(1)、A.right=C(3)、B.right=D(4)、C.left=E(5)，其他边为空。队列从左端出队，交换后的孩子按left/right次序入队：

| 出队 | 本次交换结果(left,right) | 入队后的队列 |
| --- | --- | --- |
| A | (C,B) | [C,B] |
| C | (空,E) | [B,E] |
| B | (D,空) | [E,D] |
| E | (空,空) | [D] |
| D | (空,空) | [] |

原中序为[1,4,2,5,3]，完整镜像后为[3,5,2,4,1]。若只翻根，B、C内部边未改，中序会成[5,3,2,1,4]，不是完整镜像；有深层分支时必须访问每个节点。

设I为中序、M为镜像。空树的I为空；对左右子树归纳，有I(M(T))=I(M(R))+[v]+I(M(L))=reverse(I(R))+[v]+reverse(I(L))=reverse(I(T))。A增加原197种形状及2条100节点长链共199次这项独立递归中序性质检查，同时完整保留逐原节点交换边、值不变、原根身份及第二次精确恢复的检查。只比较值序列可能被重复值掩盖，不能替代原身份合同；测试递归深度至多100，不影响生产BFS复杂度结论。
