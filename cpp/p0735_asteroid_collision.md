# 735. Asteroid Collision · C++17

[原题](https://leetcode.com/problems/asteroid-collision/)给出从左到右排列的行星，正数向右、负数向左，绝对值是大小，速度相同。碰撞时小者消失，等大时双方消失。长度为 2..10000，数值在 -1000..1000 且非零；返回全部碰撞结束后的有序幸存序列。本实现还保持输入 vector 不变。

用 vector 保存已处理前缀的最终幸存序列。只有左侧向右、右侧向左的相邻两项可能相撞；两个负数、两个正数速度相同不会追上，负数在正数左边时则互相远离。因此新值只有在自身为负、幸存栈顶为正时才需处理碰撞。

若栈顶较小，弹出它，新负值仍存活，继续检查更早的栈顶。若等大，弹出栈顶并把新值标记为消失，两者都不能再参与碰撞。若栈顶较大，新值消失，栈顶保留。循环结束仍存活的新值才追加。比较使用 `-value`，该表达式只在 value<0 时求值，且绝对值至多 1000，没有最小有符号整数取负的问题。

前缀不变量是：survivors 按原位置顺序保存当前已读前缀在碰撞结束后的结果，且内部没有相邻的正、负对。加入正值不会产生新的相向对；加入负值只可能在末尾产生碰撞。每次循环恰好执行末尾相向对的一次合法消去，再检查被暴露的末尾；新值消失或末尾不再相向时，整个序列重新稳定。因此归纳处理完全部输入即得到答案。

例如 `[6,1,-3]` 中，-3 先消去 1，随后被 6 消去，结果为 `[6]`；不能在第一次弹栈后直接保存 -3。`[3,-3,-2]` 中等大的前两项同时消失，-2 保留，不能让已经消失的 3 再挡住它。

虽然每个新值有 while 循环，但每个输入值至多入栈一次、出栈一次。使新值消失的比较对该新值也至多发生一次，总处理时间为 O(n)，不是 O(n²)。reserve 一次分配最多 n 个位置，辅助空间 O(n)，结果次序由栈内原序保持。

测试的独立 oracle 不使用前缀栈。它保存整个数组，每轮寻找任意相邻正、负对，直接 erase 较小者或等大的两者，直到无可碰撞对。分别以最左对优先和最右对优先运行。每次消去至少一个元素，过程必终止；同时可消去的两对不可能共享元素（共享项将被要求同时为正和负），其局部操作可交换，故不会因先处理其中一对而失去另一对的合法性，最终稳定结果一致。两种次序互相核对后再与实现比较。

穷举值域 {-3,-1,1,3}、长度 2..8，共 87376 个合法输入。固定 12 例覆盖等大抵消、连续吞并、较大旧值阻挡、负正远离、同向次序和数值端点。另有五个长度恰为 10000 的用例：全部同向、两组远离、两组等大完全抵消、单个 -1000 吞并 9999 个 1、单个 1000 挡住 9999 个 -1。大用例使用明确构造的期望，避免让小输入 oracle 的反复 erase 成为性能瓶颈；所有检查均断言输入保持。

连环碰撞的状态表取 `[8,3,1,-4,-8,-2,5]`。栈按原位置从左到右列出；“仍存活”表示同一个新负值还必须继续与更早栈顶比较。

| 新值或处理步骤 | 比较前的幸存栈 | 本步结果 | 幸存栈 |
| --- | --- | --- | --- |
| 读入 8 | [] | 直接保留 | [8] |
| 读入 3 | [8] | 同向，保留 | [8,3] |
| 读入 1 | [8,3] | 同向，保留 | [8,3,1] |
| 读入 -4，第一撞 | [8,3,1] | 1 消失，-4 仍存活 | [8,3] |
| -4，第二撞 | [8,3] | 3 消失，-4 仍存活 | [8] |
| -4，第三撞 | [8] | -4 消失 | [8] |
| 读入 -8 | [8] | 等大，两者都消失 | [] |
| 读入 -2 | [] | 直接保留 | [-2] |
| 读入 5 | [-2] | 互相远离，保留 | [-2,5] |

镜像性质：定义 T 为反转序列并逐项取负，即同时反射初始位置和运动方向。相邻碰撞对 `(p,-q)` 映成 `(q,-p)`，大小比较及小者消失、等大同消的规则保持，消去后的序列也正是原消去结果的 T。每步合法消去都能对应到镜像中的合法消去，稳定结果唯一，故 `F(T(input)) = T(F(input))`。原题数值绝对值至多 1000，取负不会溢出，非零与输入长度也保持。

正比例缩放性质：所有值乘同一个正整数 c，且缩放后仍在合法值域内，方向、大小关系及等大关系均不变。因此每次碰撞消去相同的原始位置，输出数值也整体乘 c。新增测试对全部 87376 个小数组检查镜像输出；再分别乘 2、7、333，检查 262128 个缩放输出。小数组原值绝对值至多 3，缩放后绝对值至多 999，每个变换输入长度仍为 2..8；原有数值端点和长度 10000 的测试保留原值，不盲目缩放端点。每个性质检查也断言输入保持。
