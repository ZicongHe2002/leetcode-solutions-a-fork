# 977. Squares of a Sorted Array · C++17

[原题](https://leetcode.com/problems/squares-of-a-sorted-array/)给非递减整数数组，返回平方后的非递减数组。`std::vector<int> Solution::sortedSquares(std::vector<int>& nums)`保持输入并新建结果；原题长度1..10000、值[-10000,10000]，平方最大100000000，32位int足够。空输入返回空vector是扩展，不承诺任意int值平方都可保存。

未处理区间用[left,right)表示，write是尚未填写的结果长度。对于任意区间内的x，若x>=0，则x<=右端值且平方不超过右端平方；若x<0，则左端值<=x<0，故x平方不超过左端平方。因此最大平方一定在两端之一。每轮选较大平方放到result[write-1]，只消耗对应一个端点；相等时选右端，另一个同样的平方仍会在后续保留。

不变量为right-left=write，以及结果[write,n)已经是所有已处理值的有序平方后缀。write>0意味着left<right，因而读取left和right-1都合法；本轮填入剩余最大值，完成后缀向左扩展且仍有序。unsigned索引只在上述非空条件内递减，最后一次不再读取已耗尽区间。重复值按出现次数处理，不能相等时同时移动两端却只写一个位置。

每轮处理一个元素，时间O(n)。结果vector占O(n)，除此之外只有端点和标量，为O(1)工作空间。测试用逐项平方后std::sort为独立oracle，枚举[-3,3]、长度0..6全部1716条非递减数组，另含一个明确期望和四个边界，覆盖±10000重复端点、全负、10000个零及10000个递增值；每次核对输入未变。

A补写nums=[−3,−1,0,1,3]的完整双端账本。right为尾后下标，write为本轮待写长度，写入位置是write−1：

| left / right / write | 左平方 / 右平方 | 消耗端点 | 新写位置和值 | 本轮后已填后缀 |
| --- | --- | --- | --- | --- |
| 0 / 5 / 5 | 9 / 9 | 右 | 4=9 | [9] |
| 0 / 4 / 4 | 9 / 1 | 左 | 3=9 | [9,9] |
| 1 / 4 / 3 | 1 / 1 | 右 | 2=1 | [1,9,9] |
| 1 / 3 / 2 | 1 / 0 | 左 | 1=1 | [1,1,9,9] |
| 2 / 3 / 1 | 0 / 0 | 右 | 0=0 | [0,1,1,9,9] |

两次平方相等时都只消耗右端，因此±3和±1的两个出现次数均被保留。最后right变2而left为2，剩余长度为0，此后不再读取端点。

对非递减输入a，定义b[i]=−a[n−1−i]。反序把大小关系反转，取负再次反转，所以b仍非递减；每项平方与对应原项相同，整个平方多重集合不变，返回的排序结果相同。只反序而不取负会破坏有序输入合同。A在枚举及四个边界的check中加入反序取负核对，取负只用于已保证的±10000范围；INT_MIN不属于此性质测试。映射后的输入单独拍快照，继续验证求解器保持输入。此性质未代替原独立平方排序oracle。
